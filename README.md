# Server-Hardening-Project-icmlabs.site
This project demonstrates a real-world Linux server hardening implementation on a production environment.  The system is secured against:  Brute-force attacks Unauthorized SSH access Open port vulnerabilities Network scanning

  -Minimize exposed ports
  -Prevent brute-force attacks
  -Improve server security posture

  -Linux (Debian)

  -Fail2Ban
